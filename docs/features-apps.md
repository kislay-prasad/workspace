## API routes (all need a session; every route checks `canSee` + the chat's write rules, validates and size-limits input, and is rate-limited where it writes)
- Tabs: `GET /api/ap/tabs?chan=` · `POST /api/ap/tabs {chan, op: add|remove|rename|url|order, type, key, name, url, multi, keys}` · `POST /api/ap/tabs/reset {chan}` · `POST /api/ap/me {pins}`.
- Tasks: `GET /api/ap/tasks?chan=` · `GET /api/ap/mytasks` · `POST /api/ap/task {chan, op: add|update|move|check|comment|attach|del, …}` · `POST /api/ap/plan {chan, op: addbucket|rename|movebucket|delbucket|label}`; server helper `ctx.apps.createTask({ chan, text, assignee, by })` (used by the teams area's workflows).
- Whiteboard: `POST /api/ap/board {chan, op: add|addmany|upd|del|front|back}` · `POST /api/ap/board/live`.
- Notebook: `GET /api/ap/nb?chan=` · `GET /api/ap/nb/page?chan=&id=` · `POST /api/ap/nb {chan, op: addsec|rensec|colsec|movesec|delsec|addpage|renpage|movepage|delpage}` · `POST /api/ap/nb/page {chan, id, v, html, title}` (409 + their page when `v` is old).
- Forms: `GET /api/ap/forms[?chan=]` · `GET /api/ap/form?id=` · `POST /api/ap/form/save|post|respond|close|clear|delete`.
- Approvals: `GET /api/ap/approvals?box=received|sent|&chan=` · `GET /api/ap/approval?id=` · `POST /api/ap/approval/new|respond|cancel`.
- Lists: `GET /api/ap/lists[?chan=]` · `GET /api/ap/list?id=` · `POST /api/ap/list/new|meta|col|row|delete`.
- Shifts: `GET /api/ap/shifts?chan=&from=&to=` · `GET /api/ap/myshifts?from=&to=` · `POST /api/ap/shifts/create|delete` · `POST /api/ap/shift {op: add|addmany|edit|del}` · `POST /api/ap/shift/request|decide` · `POST /api/ap/clock {chan, act: in|out}`.
- Bookings: `GET /api/ap/bookings` · `GET /api/ap/booking?id=` · `POST /api/ap/booking/save|delete` · `POST /api/ap/book` · `POST /api/ap/book/cancel|move`.
- Check-ins: `GET /api/ap/checkins?chan=` · `POST /api/ap/checkin {op: add|edit|del|run}` · `POST /api/ap/checkin/answer`.
- Website: `GET /api/ap/web/check?url=`. Live components: `POST /api/ap/live {id, op, …, base|v}`.
- Changed (my files): `POST /api/todo` keeps `assignees` in sync and notifies the assignee; cap 500. Wrapped (from `routes-apps.js`, behaviour kept): `POST /api/delete` (also drops `m.live` / `m.apCard`), `POST /api/edit` (cards and live components aren't edited as text).

## Known limits
- Whiteboard: moving or resizing shows for others when you let go (not while dragging); no rotation; text boxes have one style each.
- Notebook: saving is per page with a merge by blocks — two people typing in the same paragraph at the same moment get both versions of that paragraph to tidy up (no character-level co-editing).
- Website tab: the frame check needs the host to reach the page (an intranet page only your own computer can reach is shown with a hint); an `http://` site can't be framed while LANChat is on `https://`.
- Bookings are not sent as calendar invitations (the Calendar app belongs to the files area).
